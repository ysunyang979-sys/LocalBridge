# Privacy Policy

**Effective Date**: September 19, 2026  
**Applicable To**: LocalBridge v1.0.0 and subsequent releases  

---

## 1. Local-First & Zero Telemetry Commitment

LocalBridge is designed from the ground up as a **100% local-first tool**. We believe that your source code, project structure, proprietary data, and development workflows belong exclusively to you.

- **Zero Cloud Telemetry**: LocalBridge contains **no** telemetry SDKs, **no** analytics trackers, **no** error-reporting beacons (e.g. Sentry, Google Analytics, PostHog), and **no** automatic update pingers.
- **Zero Cloud Storage**: LocalBridge has no cloud servers, cloud databases, or backend ingestion endpoints.
- **Zero Code Exfiltration**: LocalBridge will never transmit your source code, file contents, project paths, Git commit history, or command outputs to any server operated by LocalBridge.

---

## 2. Network Activity & Loopback Isolation

All network operations conducted by LocalBridge are strictly constrained:

- **Loopback Interface Only**: The LocalBridge Server and Runner bind strictly to `127.0.0.1` (IPv4 loopback) and `[::1]` (IPv6 loopback).
- **No Inbound Remote Connections**: LocalBridge does not expose ports to your local area network (LAN) or the public Internet.
- **Outbound Connections**: The LocalBridge daemon initiates zero outbound Internet requests.

---

## 3. Distinction: LocalBridge vs. AI Model Providers

It is critical to understand the distinction between **LocalBridge** and the **AI Clients / Providers** you choose to connect:

```text
[ Your Local Computer ]                             [ Cloud Providers ]
┌───────────────────────────┐                       ┌─────────────────────────┐
│ LocalBridge (Local-First) │                       │ Anthropic, OpenAI, etc. │
│                           │                       │                         │
│ - Zero Telemetry          │                       │ (Operated according to  │
│ - Binds to 127.0.0.1      │                       │  provider's privacy     │
│ - Stored in local SQLite  │                       │  policy & terms)        │
└─────────────▲─────────────┘                       └────────────▲────────────┘
              │                                                  │
              │ Local MCP (127.0.0.1:18080)                      │ Upstream Cloud
              ▼                                                  ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│           AI Desktop Client (e.g., Claude Desktop, Cursor, Codex)           │
└─────────────────────────────────────────────────────────────────────────────┘
```

1. **LocalBridge Role**: LocalBridge provides a local Model Context Protocol (MCP) server running on your machine.
2. **AI Client Role**: When you connect an AI client (such as Claude Desktop or Cursor) to LocalBridge, that AI client communicates with LocalBridge over local HTTP.
3. **Upstream Transmission**: When an AI client invokes a LocalBridge tool (such as reading a file or getting a diff), LocalBridge returns the file contents to the AI client on your local computer. **The AI client then transmits that data to its respective cloud provider** (e.g., Anthropic or OpenAI) according to your arrangement with that provider.
4. **Recommendation**: We advise users to review the privacy settings, zero-data-retention (ZDR) agreements, and terms of service of their chosen AI model providers.

## 4. Local Data Storage & Retention

All data generated by LocalBridge resides solely on your computer's local drive:

| Data Type | Storage Location | Retention & Privacy Safeguards |
| :--- | :--- | :--- |
| **Authentication Tokens** | SQLite (`localbridge.db`) | Stored exclusively as one-way SHA-256 hashes (`token_hash`). Plaintext secrets are never stored. |
| **Project Registrations** | SQLite & `projects.json` | Stores only local canonical directory paths and user-assigned names. |
| **Audit Logs** | In-memory ring buffer & SQLite | Sensitive file contents, patches, command args, stdout/stderr, and tokens are **strictly stripped** using `SafeAuditMetadata` field whitelisting. |
| **File Backups** | Local project `.localbridge/backups` | Maximum 100 backups per project (100 MiB quota). Stored locally for recovery purposes. |
| **Pending Approvals** | Memory & local state | Expire after 300 seconds; purged automatically upon runner restart. |

---

## 5. Complete Data Deletion

You retain complete ownership and control of your data at all times. To completely erase all traces of LocalBridge from your system:

1. **Uninstall the Application**:
   - Use Windows "Add or Remove Programs" or run the uninstaller in the installation directory.
2. **Remove Local State & Databases**:
   - Delete `%APPDATA%\localbridge` (or the custom `--state-path` directory if configured).
   - Delete any `.localbridge` backup folders inside your authorized project repositories if no longer needed.
3. **Result**: All cryptographic keys, project references, database tables, and audit logs are permanently removed with zero lingering remote backups.
