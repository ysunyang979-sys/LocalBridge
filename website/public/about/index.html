关于 Nexus (About Nexus)

Nexus — Local AI Control Plane & Secure MCP Bridge for Local Development.

什么是 Nexus？

Nexus 是专为 Google Gemini Spark、OpenAI ChatGPT 与 Claude 打造的本地安全控制中枢（Local AI Control Plane）与生产级 MCP 桥接网关。

在不牺牲本地计算机与源码安全的前提下，Nexus 帮助开发者将本地项目、Git 工作树与开发工具链无缝连接至前沿大语言模型。

核心设计原则

  • 本地零信任 (Zero-Trust Local Execution)：源码与文件系统索引 100% 留存在物理机本地，不向未经许可的云端上传代码。
  • 协议标准化 (Protocol Compliance)：完全支持 Model Context Protocol (MCP 2.0)、RFC 8414、RFC 9728 与 OAuth 2.0 PKCE。
  • 人机协同审批闭环 (Human-in-the-Loop)：高危指令与写操作必须在物理桌面端获得人工点击确认。
  • 开箱即用自包含 (Self-Contained Runtime)：安装包内封装经过验证的 Node.js 24 独立运行时与核心模块，无需安装复杂依赖。
