Nexus 官方技术文档概览 (Documentation)

Nexus 快速上手、架构拓扑、安全策略与模型连接参考手册。

欢迎查阅 Nexus 官方技术文档。本手册旨在帮助开发者快速掌握 Nexus 的安装、工程授权、模型集成与安全控制策略。

📚 目录指引

1. 快速上手

  • 系统要求：Windows 10 / 11 64-bit，至少 4GB 内存与 300MB 可用磁盘空间。
  • 安装客户端：运行 Nexus_1.2.0_x64-setup.exe，启动后程序将常驻于系统托盘。
  • 授权项目：在桌面主控台进入 Projects 页面，点击 + Authorize New Project 添加本地目录。

2. 模型接入与配置

  • Google Gemini Spark：
    • 进入 Connections 页面，一键启动内置 Cloudflare Tunnel。
    • 将生成的临时或自定义域名（如 https://xxx.trycloudflare.com/mcp）配置到 Gemini Spark 的 Tools 设置中。
  • OpenAI ChatGPT：
    • 通过专有网关挂载为 Custom Action 或 MCP 协议客户端，提供受控的只读与写操作。
  • Claude Desktop & Cursor：
    • 直接在 claude_desktop_config.json 中配置本地 stdio 进程启动命令。

3. 安全策略与三级审批

  • SAFE（只读免审）：读文件、获取目录结构、Git status，4ms 内毫秒响应。
  • CAUTION（修改确认）：修改文件、打补丁，桌面端弹出前后 Diff 等待开发者点击批准。
  • DANGEROUS（严格阻断）：系统级命令执行或文件删除，默认严格拦截。
  • Emergency Halt：随时点击右上角红色急停按钮，瞬间强制终止全部运行中子进程。
