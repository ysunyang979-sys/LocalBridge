WHY NEXUS

让前沿 AI 在本地严密受控下大显身手

100% 本地优先

所有代码阅读、文件树检索、代码补丁均在用户电脑本地执行。支持目录白名单物理锁定（Jail 限制），绝无未经授权的代码上传云端风险。

三级人机协同审批

自动将操作划分为 SAFE（安全只读）、CAUTION（写入确认）与 DANGEROUS（高危阻断）。开发者拥有最终裁决权，并可随时发起限时免审会话。

原生前沿模型生态

原生支持 Google Gemini Spark 与 OpenAI ChatGPT。搭载带 PKCE 的企业级 OAuth 2.0 验证规范，全兼容 Claude Desktop 与各类 MCP 客户端。

LSP 语法级代码智能

内置 TypeScript / ESLint Language Server。AI 能够以 AST 抽象语法树级别进行符号定义跳转、跨文件引用查询和编译报错诊断。

硬件级瞬时急停 (Emergency Halt)

一旦发现异常，一键发送系统级强杀信号（SIGKILL / Taskkill）并断开桥接端口，彻底阻断任何未完成的文件写入或网络请求。

内置技能与合规验证

预置针对代码排错、Git 审查、构建修复等 8 大开箱即用技能。支持从 ZIP 包热加载技能，严格校验权限清单防范恶意插件。

事务级本地审计日志

基于 SQLite WAL 引擎记录每一步工具调用的时间戳、参数散列、耗时与审批结果，满足企业安全合规回溯需求。

FAQ

常见问题

Nexus 会把我的代码上传到第三方云服务器吗？

绝对不会。Nexus 是 100% 本地优先（Local-First）架构，所有代码检索、语法分析和补丁应用均在本地沙箱完成。只有在 AI 调用特定工具时，工具所产出的局部输出才会依规范返回给对应的大模型会话。

什么是三级人机协同审批（Safe / Caution / Dangerous）？

只读查询（如读取文件、查找符号）归类为 SAFE 级别，自动通过无需打扰用户；文件修改或写操作归类为 CAUTION 级别，弹出审批提示由用户点击确认；危险指令（如跨目录删除、系统级提权命令）归类为 DANGEROUS，将被严格拦截。

我不需要预先安装 Node.js 或 Rust 环境吗？

不需要。直接下载 Nexus Windows 安装包（`Nexus_1.2.0_x64-setup.exe`），安装包内已完整打包了经签名的 Node.js 运行时及全部内置服务，开箱即用。
