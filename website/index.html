Core Features

绝对沙箱与规范路径校验

所有文件读写均强制通过操作系统原生真实规范路径（Canonical Path）比对，无死角防御 ../ 跨目录、符号链接绕过（Symlink Escape）与 Windows Junction 越权访问。

双 Token 体系与敏感文件屏障

FAQ

常见问题解答

Nexus 采用严格的三层安全防线：1. 只读/受控授权：只有在桌面端主动添加的目录才能被访问，未授权目录对 AI 完全不可见；2. 规范路径防逃逸：所有读写均在 OS 真实规范路径层面校验，阻断任何跨目录与软链接逃逸；3. 敏感文件屏障：.env、私钥与证书等关键凭据默认物理阻断，不会发往 AI。
由于开源免费版本未集成苹果付费公证证书，首次启动时系统 Gatekeeper 会提示未签名。解决方式很简单：在系统的「系统设置」->「隐私与安全性」中点击「仍要打开」；或在终端中执行：xattr -cr /Applications/Nexus.app 即可直接启动。
Linux 版本计划支持 Ubuntu、Debian（提供 .deb 包）、Fedora、Arch Linux 以及通用 AppImage 独立包。当前已进入最后的沙箱边界与 systemd 服务兼容测试阶段，即将于下一次更新正式推出，您可以 Star 官方 GitHub 仓库第一时间获取发版通知。
Nexus 完全遵循开源开放的 Model Context Protocol (MCP) 规范。除了完美适配 ChatGPT Web / Desktop 端外，还天然兼容 Claude Desktop、Cursor、Windsurf、Zed 等所有主流支持 MCP 协议的开发工具。
